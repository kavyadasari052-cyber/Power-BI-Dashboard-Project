Father–Daughter Financial Goal & Savings Tracker

📊 Project Overview

This project is an interactive Power BI dashboard designed to track and analyze father–daughter financial goals, savings, expenses, and overall financial progress.

The dashboard provides clear visual insights into savings patterns, expenses, financial targets, and goal achievement, helping users make better financial planning decisions.

🎯 Objectives

- Track monthly savings and expenses
- Monitor financial goals and targets
- Analyze savings progress
- Compare planned and actual savings
- Provide interactive financial insights
- Support better financial decision-making

✨ Key Features

- Interactive Power BI dashboard
- Financial goal tracking
- Savings analysis
- Expense analysis
- Monthly financial trends
- Goal progress visualization
- Easy-to-understand charts and KPIs

🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Visualization
- Data Analysis
